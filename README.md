# TECO! — instaladores

Jogo arcade 3D de bolinha de gude. Este repositório guarda só os instaladores e os arquivos de
atualização; o código fica em um repositório privado.

## Como instalar

1. Abra a aba **Releases** e baixe o `TECO-Setup-<versão>.exe` mais recente.
2. Abra o instalador. Ele ainda não tem assinatura digital: se o Windows mostrar "O Windows protegeu
   o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Pronto: o atalho **TECO!** fica na área de trabalho.

## Atualizações

O jogo procura versões novas sozinho quando abre, baixa enquanto você joga e atualiza quando você
fecha (ou pelo botão **Atualizar agora** no menu). Não precisa baixar de novo.

## Online

O online usa a rede da Steam. Antes do jogo estar na loja, use o atalho
**TECO Online (teste Steam)** na pasta do jogo, com a Steam aberta, e jogue com teclado e mouse.
